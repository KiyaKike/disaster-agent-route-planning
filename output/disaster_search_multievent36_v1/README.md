## 当前决策

**本批跨事件测量未通过预先固定的条件，暂停在当前局部合同上继续调规划策略。** 三个事件中只有尼泊尔达到6个局部可发现场景；海啸虽有2个严重参考场景，但看完所有局部块仍无真阳性，不能靠选点顺序补救。龙卷风的静态主预算召回2.32%，低于随机期望11.75%；不能把SantaRosa的静态优势推广到这些事件。

局部全网格严重像素精度/召回/F1：尼泊尔23.63%/53.57%/32.80%，海啸0%/0%/0%，龙卷风54.56%/47.01%/50.50%。这些结果限定于当前权重、256局部输入和发布参考；没有证明所有模型或观察方式都不可行。海啸仅3栋严重源对象、龙卷风10栋，当前小样本也限制了强结论。新36完整保留，未补挑阳性、并入旧SantaRosa或改阈值。

下一项先做感知迁移/参考适用性的证据复盘，收缩研究范围；继续增加复杂规划的依据不足。当前2308次前向在本机运行约125秒，算力不是本轮主要瓶颈，暂不租GPU。

## 来源、质量与准入

作者完整训练/验证/测试清单与TACO身份路径集合逐一相等，共11034对。TACO三个事件候选池分别619/148/343，按SHA256(seed|event|ID)取前12，不读损伤、建筑数、几何或预测挑样本。未采用原镜像较少的身份池；没有先筛出“有建筑/有损伤”场景。

36对72张原图，载荷106554040字节；含所需元数据/共享标签的新网络接收合计 106,639,088 字节，低于预设384MiB上限，RGB低于256MiB。新RGB都核对PNG完整性、尺寸、编码、SHA和像素哈希；与已有本地1024原图对及本批精确影像对重复检查通过。全零RGB至少25%的影像 2 张，最大零值比例 57.19%；仅标记，所有36对保留，无删图、无像素过滤。精确零值不是经人工验证的云/无效掩膜。

损伤列可能与旧保留/未选样本共享物理Parquet列。可信提取器只返回固定36行；共享损伤字节瞬时读取，不缓存、不输出其他样本结果。派生多边形保持原坐标及旧半像素容差，未知及冲突参考忽略；没有恢复原始UID或创造人工标注。标签来源为发布参考，缺少原始灾前定位真值，不是官方mixedF1、实例AP或真实现场识别率。

## 判断与下一步

满足每事件至少6个局部可发现场景的事件数：1/3。前瞻筛查：`INSUFFICIENT_CROSS_EVENT_MEASUREMENT_SIGNAL_DO_NOT_TUNE_PLANNER`。这是工程测量密度筛查，不是发表门槛，也不表示其他事件没有损伤。结果不足时停止在当前跨灾害合同上增加规划变体；不能因这轮结果补挑阳性、并入SantaRosa或重选阈值。若充分，再审查一个反馈机制的研究差异并设计独立确认数据。
