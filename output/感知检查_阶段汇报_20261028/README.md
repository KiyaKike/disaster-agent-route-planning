# 感知检查阶段汇报材料

先看《感知检查阶段汇报.docx》：4页可编辑汇报稿，包含双检查点诊断、整图和局部观察对照、跨事件失败结果，以及后续回到灾前灾后路线规划的安排。该稿已逐页检查中文显示、表格和图表。

《口头汇报要点.txt》可用于组会口头说明；《实验索引.csv》列出11个阶段及原始目录。

“证据快照”复制了各阶段的README、完成收据和可用关键JSON。快照保留当时结论及后续建议，不代表这些旧建议仍是当前主线；当前以“路线主线与感知支线.json”为准。

原始影像、权重、代码、完整预测缓存、失败图及旧实验协议均留在项目原目录。本包为汇报用轻量证据整理，不重复复制大型数据。迁移到其他电脑时，实验索引中的绝对原目录需相应调整；包内快照可以独立查看。

“来源校验.json”绑定43份用于本次汇报的源文件；“归档校验.json”绑定本包主要输出。汇报整理没有新增模型调用、训练或GPU支出，也没有改动原始实验文件。

后续主线为灾前初始路线、灾后信息更新和沿途反馈重规划。感知检查独立归档，作为固定输入与观测不确定性的参考；它们不等于路线算法收益、现场真值或可执行飞行航线。
