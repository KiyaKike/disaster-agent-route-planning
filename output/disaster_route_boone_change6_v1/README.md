# 只保留最后6维差分：实际消融结果

2026-11-03。已在`run_boone_context_experiment.py`增加`--feature-mode change-only`，实际执行`features[:, 30:]`。复用已封存的12栋VLM初始分数、锚点UAS视角标注、空间距离、50m空间尺度及0.5残差系数；没有新增模型推理或路线运行。

## 整体结果

以UAS作者视角标签为参考，12锚点等权平均。

|方法|特征核宽tau|AP↑|Brier↓|前3名来源阳性数↑|
|---|---:|---:|---:|---:|
|不更新|—|0.377447|0.202927|0.917|
|纯空间|—|0.459772|0.209145|0.917|
|原36维＋空间|8.6306|0.435941|0.206128|0.917|
|仅6维，原规则重估核宽|3.1526|0.362848|0.208802|0.583|
|仅6维，固定旧核宽|8.6306|0.474223|0.208733|1.000|

**直接切片并沿用原来的核宽估计规则，AP从0.436降至0.363。切片且固定原核宽数值，AP为0.474，较纯空间高约0.014。** 两组在查看本轮得分前一并定义，均保留，不择优隐藏另一组。

核宽影响大：重估得到3.1526，原值是8.6306。固定旧值时，6维相似度的非对角均值0.922、中位数0.935；原36维相似度均值0.631，中位数0.607。门控整体更接近1，负反馈更新也更接近纯空间。因此0.474的提升既可能含相似关系变化，也可能含整体门控强度变化，需要下一项匹配强度的空间对照隔离，不能直接归因于“去掉颜色必然更好”。
