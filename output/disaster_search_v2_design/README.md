## 研究目标与评价

给定粗分辨率灾前后 RGB 线索、固定感知器和观察预算，选择初查与复核区域，尽量增加**新发现的不同严重受损建筑数**。目标仍为 major-damage / destroyed。建筑实例及损伤真值仅供评价器使用。

主指标：质量混合、预算 32、原图升级成本 2 时，每个事件先平均每场景的去重发现数，再对事件等权平均。另报所有预算/质量/成本、逐事件结果、建筑召回、误报、未匹配阳性、首次发现成本及发现曲线。无目标场景召回为 null。

目前沿用并明确标注旧可见轮廓匹配是工程代理；在新数据评分前必须完成边界检查，所有固定轨迹按 5%/10%/25% 可见轮廓覆盖重算。若更换发现定义，须在新验证/确认结果之前另立版本，不能按最佳成绩选择阈值。

选点效用改为**预计新增建筑数 / 成本**；原来的存在性效用作为待补消融。模糊阳性也允许一次原图复核，不能自动当作“该格已无新增发现机会”。升级使用与此前模糊结果联合或条件建模的统计。相关观测/同格数量组件已在六开发样本接入工程搜索，尚未完成全开发拟合或精确跨格新增收益模型。

## 实验顺序和继续标准

1. 数据准入：固定来源与许可、对应关系、实例多边形、未知类别、像素和可得地理信息。保留阴性场景；目标构成不足时报告局限，不补挑阳性图。
2. 简单对照：随机、空间覆盖、先验初查；随机/先验加简单复核；新增建筑数贪心与相关观测基线。动作、成本、观测和拟合数据公平共享。
3. 强对照：在提出新方法之前，明确 ENS / MF-ENS 或 rollout 的适配方案及预算差异。相关工作见 `related_work.md`。本阶段不预选新主方法。
4. 验证筛选：未来预先固定的候选需较各简单基线达到至少 10% 相对增量和 0.1 栋/场景绝对增量，至少 2/3 个有目标验证事件方向一致，误报增加不超过 0.05 格/场景。这是工程继续阈值，不是显著性检验。
5. 只有测量、基线与方法均锁定后再使用最终确认结果。随机种子先在场景内平均，事件单独报告；不能用种子或网格数量替代独立灾害数量。

预算为 8/16/32，升级成本为 1/2/4；主要设置提前指定为 32 与 2。成本是观察代理，未包含飞行、返程与真实新视角。当前本机计算足够，暂不租 GPU。
