# Strong Baseline：256 局部观察与面积预算诊断

2026-10-28。固定现有 Santa Rosa24 对，新增384个原生256观察块。该阶段检验局部测量与策略空间，不提出新反馈方法。

## 主预算结果

主预算16＝购买4个256块，占1024整幅原图面积25%。每块配对灾前/灾后原图，取得后执行作者4翻转；每个预算内轨迹包含16次模型前向。两日期作为一对按面积计费，计算次数另列，不把翻转当作免费计算。下表随机项为精确期望，不选随机种子。

| 条件 | 24场景合计正确发现严重参考像素 | 合并参考召回 | 阳性场景平均召回 |
|---|---:|---:|---:|
| Exact random | 155,163.2 | 21.48% | 20.83% |
| Coarse-change static | 263,412.0 | 36.47% | 36.78% |
| Oracle diagnostic bound | 372,190.0 | 51.52% | 65.33% |

Oracle 比静态多覆盖 108,778 个参考像素，是已知全部真实动作收益后的离线上界，不能当成可执行 Agent 或新方法收益。静态策略只读64×64免费粗图的平均 RGB 变化；这份低分辨率先验免费是仿真假设，不能宣称实际感知完全无成本。排序在新推理前已冻结，不使用全幅高分辨率变化、严重参考、当前预测或未来反馈。

## 当前判断

已测的可执行基线中，免费粗图变化排序的合并发现量高于均匀随机。主预算静态到Oracle的合并召回差为 **15.06 个百分点**，只是可供进一步研究的诊断空间；尚未运行反馈控制器，无法把这部分差距写成方法提升。相同预算下，随机期望计数之比精度76.51%，静态79.32%，Oracle80.02%。

局部全网格相对旧整图的精度降低3.35个百分点、F1降低1.91个百分点，尽管召回接近，不能据此认为裁块没有代价。下一步优先按相同合同做新多事件复验；如这些机会只存在于Santa Rosa，就收缩跨灾害结论。

## 局部输入保留了多少信号

全部16局部块都观察时，严重像素精度 76.51%、召回 85.92%、F1 80.94%。旧1024整图召回 86.07%；局部全网格召回保留比例 0.9982。这比较输入上下文适用性，不是预算内方法增益。

24场景中有严重参考 18 个，其中局部全网格至少有一个真阳性的场景 18 个；完全漏检阳性场景：无。全部24个固定场景及既有黑色影像区域均保留，未知/冲突参考255排除，未按预测挑阳性或删除失败。

## 复核与解释边界

357项测试通过。4次旧整图回归调用和1536次新局部调用，共1540次MPS前向；前向累计 80.33 秒，含缓存保存循环 100.72 秒。旧整图概率均值和最终掩膜已复现。没有训练、新RGB、网络下载、付费GPU或旧保留集评分。

独立重建1540个输入，重新解码384份局部概率、重建24份多边形参考，重放384个块评分、288个预算/策略评分和12个汇总；逐场景/预算穷举所有均匀子集核对随机期望与同成本Oracle最优性。59份旧冻结源码不变。

随机精度/F1列若查看原始JSON，含义是“期望计数之比”，不是非线性指标本身的期望；召回对固定参考线性，随机召回是精确期望。本阶段无可学习策略、无训练，无统计独立方法收益声明。Santa Rosa符合作者训练未见事件清单，但已为本项目开发使用，且仅一个事件，不是新独立/跨事件验证，也不是官方mixedF1或逐栋人工真值。

前瞻工程筛查固定为至少6个参考阳性且局部可发现场景，并保留至少一半旧整图合并召回；这只是防止在无测量信号时继续调规划，不是发表门槛。工程筛查结果：True；Oracle相对静态的主预算空间大于0：True。当前决策：`PROCEED_TO_PROSPECTIVE_MULTIEVENT_MEASUREMENT_ONLY`。
