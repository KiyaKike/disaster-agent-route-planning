# 可推进的候选方向与真实数据入口

2026年11月3日。当前工作已有基线、预算核验和负结果分析，尚无得到独立支持的方法贡献。旧36对上继续修改反馈规则不作为主线。

## 推荐研究问题

**面向跨源不确定证据的预算搜查／复核路线规划。** 核心问题是：获得新的无人机观测可能改变哪些建筑的判断，是否值得为此消耗移动、观察和返程预算？双层地图保存初始线索与已付证据，收益需要来自选点和路线方法。

这是待验证的候选，不宣称新颖性或已取得提升。与原邻域传播的区别是先核实同一建筑的跨源可对应观测，不默认其他建筑具有相同损伤状态。新增观测也不能默认优于原观测；跨源标签不一致可能来自可见性、时相或判读差异。

## 本轮已经核实

作者发布库：[CRASAR-U-DROIDs](https://huggingface.co/datasets/CRASAR/CRASAR-U-DROIDs)。固定版本 `4c2732a7ab9658517ca8caa69bfee9e1f87ca532`。

- 文件清单包含UAS、SATELLITE等来源的GeoTIFF及建筑标注。作者说明提供建筑ID、地理／像素轮廓和配准调整。
- 按文件名顺序选择第一个具有卫星对应文件的训练集UAS场景，不按损伤类别或预测成绩选样。
- 实际读取 `090302-Pecan-Grove-Levee` 的两个训练标注文件：UAS有660栋，所选卫星文件有640栋，**639个building_id可对应**，两份文件均提供地理轮廓。
- 共读取约2.4MB训练标注及约110KB库元数据，没有下载大影像、读取测试标注、统计损伤一致性或运行新感知模型。已读取的训练场景只作开发资格检查，不再称独立确认集。

详细路径、SHA256及检查结果见[feasibility.json](feasibility.json)。该版本可能不同于2024论文的原始规模和划分，后续只使用固定版本的实际清单。

## 还不能认定的条件

卫星—无人机不等于灾前—灾后。需要核验拍摄时间；底图轮廓也需核实来源时间，才能称灾前先验。当前仅证实建筑ID可连接，未验证影像CRS、空间重合、像素配准、观测可见性或同建筑重复UAS视图。

这批数据是正射影像，并未因此获得原始相机位姿、真实飞行轨迹、航时／能耗或可执行空域。它有望支持有地理参考的任务规划回放，不直接支持真实飞行结论。建筑损伤标注保留给独立评分，不能直接作为Agent的免费先验或付费预测。

## 下一轮的具体交付与判定

1. **数据资格检查**：固定小区域，核验时相、GeoTIFF变换、建筑连接与实际视图覆盖。灾前数据未落实时，明确标成“灾后跨源核查”，不能冒称完成灾前灾后实验。没有可用重复视图时，不设置重复观察动作。
2. **任务与强基线**：固定感知输出，明确定义一次付费观察能看到哪些建筑，避免多视图重复计分。保留距离优先、损伤线索优先、简单不确定性优先、同效用充分求解静态路线，并统一所有费用。
3. **方法验证**：在资格通过后，检验由真实观测支持的复核价值估计与路线联合选择；先比较同预算的任务收益、错误判断、距离与耗时。算法及指标先固定，再在不参与开发的新场景评价。

若只有数据接通而没有强基线上的收益，仍不能称方法贡献。若数据资格不通过，就保留失败记录，收敛为受控规划研究或寻找合作数据，不回到旧36对调邻域阈值。

相关作者工作：[跨源损伤标签一致性代码与数据入口](https://github.com/TManzini/NowYouSeeItNowYouDont)。该工作说明跨源比较已有研究基础；本项目若继续，应在观察选择和路线决策上提出并验证区别，而非只复现一致性统计。
