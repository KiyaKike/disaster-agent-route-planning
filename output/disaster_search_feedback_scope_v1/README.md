# 反馈传播范围诊断

本轮是看过旧版失败后的校准侧探索。先固定诊断定义，再比较同变化分档、相邻八格、相邻且同分档、远处同分档四种关系。没有用验证/测试标签选择关系。

主分析剔除共享严重损伤建筑 UID 的格子对，避免同一栋建筑跨格就制造出“反馈可传播到其他建筑”的假象。这个剔除仅用于评价诊断；在线规划器没有真实 UID，也不按它定义邻域。

| 源格与候选格关系 | 同场景内，源格有/无目标时的候选目标率差，场景等权 |
|---|---:|
| 同分档，任意距离 | 4.7 个百分点 |
| 相邻八格 | 16.6 个百分点 |
| 相邻且同分档 | 21.7 个百分点 |
| 远处同分档 | 1.7 个百分点 |

上述对比在 13 个同时有两类源格、且存在合格候选对的场景中计算，每个场景等权。不同关系包含的格子对不同，不是匹配后的因果比较，也没有独立事件层面的显著性结论。它提供缩小传播范围的依据，尚未证明搜索收益。

另用固定传感器观测计算单次反馈后的候选概率，再以候选真值评价 Brier 误差。更新保留原来的倍率 4、收缩 8 和可靠性权重，不根据候选标签产生更新。先按源格平均、再按场景平均，避免密集建筑场景通过格子对数占据全部权重。

原图阳性反馈：同分档全局传播的平均 Brier 变化约 -0.00490，相邻且同分档约 -0.01001；负数表示误差降低。局部规则仍有 6/15 个有阳性观察的场景受到伤害，不能概括为阳性总是适合传播。

阴性反馈也并非一律有害：相邻且同分档时，原图阴性反馈的平均 Brier 变化约 -0.00074，但 Harvey 为 -0.00199、Santa Rosa 为 +0.00051。场景密度和事件差异仍存在，不能凭合计值决定统一抑制远处区域。

因此下一轮固定比较：局部正负残差、局部仅阳性残差、简单阳性邻格偏好，继续保留质量门控与旧全局传播对照。其结果见 `../disaster_search_local_feedback_v1/README.md`。

定义与全部结果分别保存在 `diagnostic_protocol.json`、`diagnostic_report.json`，包括不剔除共享 UID 的对照、逐场景与逐事件值。所有参数由此前校准数据拟合，本文不是独立验证报告。
