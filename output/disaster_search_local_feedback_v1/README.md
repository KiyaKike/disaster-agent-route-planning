# 局部反馈校准侧跟进

新增三种固定局部规则，共 1512 回合；另复用哈希核查通过的 1512 个旧对照回合。没有按结果搜索邻域、反馈强度或预算。全部方法仍使用同一场景、质量分配、观测缓存和成本。

这一步在看过校准诊断后设计，属于探索性结果。后续冻结验证见 `../disaster_search_validation_v1/README.md`，不能只用本文件的较好数字判断机制有效。

## 三种规则

- `local_residual`：只有相邻八格且原始变化分档相同的已观察格参与传播；正负反馈都保留，可靠性、倍率 4、收缩 8 和裁剪范围沿用旧版。
- `local_positive`：同一邻域与公式，只允许最新观察为阳性的格子传播。
- `neighbor_positive`：简单对照，只要邻域有最新阳性观察，未访问格的 logit 固定加 0.25；无概率残差或质量加权。该常数透明固定，未做优化，不代表最强启发式。

所有已观察格继续使用质量条件后验，锚定原始拟合先验；邻域修正仅影响未访问格。模糊阴性升级为原图时，用最新代表替换旧残差，不重复累计。邻域只依赖公开网格坐标和变化分档，不接触目标 UID 或未来观测。

## 核查与文件

`integrity_checks.json` 记录独立复算 1512 回合、26151 步：每一步重新计算合法动作、效用、公开邻域、残差、原始先验后验、预算和建筑去重，均通过。局部邻域限制、阴性阻断、相关证据替换、真值不影响动作等单元检查通过。最新完整 58 项测试日志在 `../disaster_search_validation_v1/test_log.txt`。

- `search_protocol.json`：执行前固定的三个规则、全部对照、成本与评价要求。
- `traces.jsonl`：三个新规则的完整轨迹。
- `runs.json`：新规则与复用对照的逐回合结果。
- `report.json`：所有条件/预算结果及相对门控、简单邻格的场景与事件差值。
- `integrity_checks.json`：独立动作和评价复算。

仍是校准侧结果，权重训练暴露与人工模糊/恢复代理限制都保留。相邻关系的统计支持和校准侧收益都不能替代验证。
