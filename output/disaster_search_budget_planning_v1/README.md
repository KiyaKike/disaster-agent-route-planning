# 72 开发场景：预算规划适配与效用分辨率诊断

**已完成同参数的贪心、两步前瞻和剩余预算批量近似对照。主要设置下，批量规划改善了数量贪心，但仍未超过简单原始变化排序；本轮不选新主方法，先排查效用分档造成的排序损失。**

本轮属于开发探索，没有新增感知推理、图像下载、参数拟合、控制器训练或 GPU 租用。验证和最终确认未评分。读取的新增外部材料只有两篇原始论文及其官方页面。全部旧数据、参数、预算对照和失败记录保留。

## 主要结果

质量混合、预算32、复核成本2、10%可见轮廓覆盖匹配。种子先在场景内平均，再平均事件内场景，最后对三个事件等权平均。单位为不同目标建筑/场景；Mexico仍保留为零，不作为成功迁移事件。

| 策略 | 全72开发拟合 | 用另两个开发事件拟合 |
|---|---:|---:|
| 原始数量贪心 | 5.667 | 4.753 |
| 两步前瞻 | 5.672 | 4.747 |
| 剩余预算批量近似 | 5.833 | 5.025 |
| 原始变化排序，只初查（上一轮固定对照） | 6.106 | 6.106 |

批量近似相对原始数量贪心增加 **0.167栋/场景，约2.9%**；开发事件留出时增加0.272栋/场景，约5.7%。但相对原始变化排序仍分别低0.272和1.081栋/场景。它在样本内也低于仅阴性复核的6.067和存在性效用的6.075；不能据此宣称规划候选已经胜过简单基线。

主要设置的已知阴性误报为：批量近似0.108、原数量贪心0.114、原始变化排序0.186格/场景。发现数与误报都报告，不把排序对照较高的发现数等同于所有指标更好。

两种拟合范围都属于开发结果：全72拟合的评分是样本内；留一开发事件用的是已经检查过的开发数据，也不是独立验证。没有据此更换主要成本或拟合参数。

## 原文核查与具体适配

[Jiang等，ICML2017，§3、式(6)(7)](https://proceedings.mlr.press/v70/jiang17d/jiang17d.pdf)的ENS采用一次假设查询后，用剩余预算对应的高概率批次近似后续价值。[Nguyen等，ICML2021，§2.1、§3.1–3.2](https://proceedings.mlr.press/v139/nguyen21f/nguyen21f.pdf)区分准确高保真与带噪低保真查询，并在MF-ENS中加入探索性低保真批次。本任务是串行付费初查/复核，两种模式均为带噪模型输出、两者都可增加工程发现奖励。因此，本轮是**受ENS启发的成本适配基线，不是ENS/MF-ENS忠实复现**，也没有完成MF-ENS的探索批次。

具体差异在运行前固定于 `adaptation.md`，其哈希和原始PDF/页面哈希写入 `protocol.json`。原算法页已经渲染检查，来源保存在 `sources/`。

原数量贪心使用上一轮完全相同的数量参数、质量、动作和收益/成本排序。两步前瞻最大化当前奖励加下一次可承担动作的期望奖励，之后价值为零；不能称为完整预算规划。

批量近似计算当前奖励，加上假设结果下、剩余预算中当前可执行动作的背包最优价值。每格至多一个批量动作，初查成本1、复核成本固定；用两类奖励的排序前缀和及复核数量枚举，精确求出这个**批量子问题**。只有第一个假设初查会解锁其条件复核；批次里其他未来初查之后的复核解锁没有展开。实际执行每次只做一个付费动作，再重新规划。整个自适应过程仍是近似。

假设分支只使用冻结的粗图真值先验和成对模糊/原图声明概率，以及已有的模糊条件复核数量均值。规划看不到真实建筑ID、未来掩膜或下一格实际质量，不将相关边际似然独立相乘。不同格在这个代理里不相互更新，假设奖励按同格数量相加，未精确建模跨格真实建筑重复。因此，更充分地优化代理并不保证真实去重发现提高。

候选合并仅利用相同状态、奖励、分支概率的公开参数类，保留行列最前格，不按成绩截断候选。规划值在1e-12内并列时，先比较原贪心收益/成本，再按行列。规则在评分前固定，没有事后调参。

## 下一步线索：四档效用的大量同分

完成规划评分后，另做了一项不读取标签或未来观察的公开特征诊断：

| 初始初查分数 | 全开发拟合 | 另两开发事件拟合 |
|---|---:|---:|
| 每场景不同数量效用值均数 | 3.83 | 3.83 |
| 最高效用并列格数均数 | 16.13 | 17.58 |
| 原始变化分数不同值均数 | 51.03 | 51.03 |
| 初次选择与原始变化最大格不同的场景数 | 70/72 | 68/72 |

四档数量效用将很多不同粗图线索合并，当前规则再按行列处理同分。这证明了分数分辨率损失，**不证明差异格一定更差，也不证明改同分规则会增加发现**。诊断见 `utility_resolution.json`，它不是另一组策略成绩。

按照上轮预先记录的继续原则，当前规划版本仍不胜简单先验/门控，因此不继续增加规划深度或控制参数。下一轮先固定一个小型消融：原行列同分规则、原始粗图变化作为同分次序、固定随机同分次序；保留完全相同的四档效用、模型、动作和预算。只有验证这个机制影响之后，才决定是否需要保留更细的效用排序。这个候选实验尚未实现或运行，执行前另立协议，不能将本轮诊断写成改进效果。

这项同分机制属于基线实现和诊断，不自动构成论文创新。完整MF-ENS对照、感知/空间准入及独立验证仍有缺口，本轮没有选定新主方法。

## 完整性与核查

30,240条规划轨迹、90,720条阈值评分，542,439个动作逐步核查通过，包括59,303次复核和5,268次阳性复核。每场景420个配置。全部预算、动作资格、固定质量分配、实际付费布尔结果及三个阈值评分重放通过；原数量贪心的10,080个配置与上一轮逐动作一致。原图模式下两种规划与贪心动作顺序均一致，符合此独立代理的对称性检查。

批量近似和两步前瞻分别改变5,277和4,955条相对贪心的轨迹，不能把两步效果接近零误解为机制没有执行。144项测试通过，其中背包子问题与小规模所有子集穷举一致，测试覆盖奖励/成本单位、剩余预算、假设分支、同分合并、旧贪心复现及私有字段隔离。

全部规划计算约24.3秒，主运行约27.3秒，另计来源核对、审计和绘图。轨迹和评分分别压缩保存，评价数据没有传入选点函数。旧六样本、完整开发数据、拟合、预算对照及失败记录保持不变。验证/最终确认未评分，未使用付费GPU。
