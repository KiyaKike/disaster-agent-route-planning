# 四档数量效用的同分处理对照

2026-10-25。**运行与回放审计已完成，尚未选定新主方法。** 结果表明同分处理会明显改变数量贪心的成绩；但仅恢复原始变化分数作为同分依据，没有稳定增益。在全部开发场景拟合的主要设置中，固定随机同分使数量贪心超过批量尾项，上一轮规划的优势不再成立。开发事件留出仍有部分规划增益，但均低于简单变化排序。

## 固定条件与实现

- 只使用已许可的72个开发场景和9,216个固定感知缓存；不重新拟合、推理、下载图像或租GPU，验证/确认不评分。
- 复用上一轮四档数量效用、联合观测参数及事件留出模型。三种决策器为数量贪心、两步前瞻、批量尾项；批量尾项仍是ENS启发的串行成本适配，未实现完整MF-ENS。
- 主要设置保持混合质量、预算32、升级成本2、匹配覆盖10%。开发拟合跑完整3质量×3预算×3成本；开发事件留出只跑主要配置。全部轨迹均按5%/10%/25%覆盖评分。
- 同分规则：原行列顺序；同分时优先初始公开变化分数高者；固定随机格子顺序。原始变化分数完全相同则按行列。随机顺序使用既定10个种子20261030—20261039，质量种子为20261025—20261029；不选择最佳顺序。
- 一条轨迹内的随机顺序固定，同一顺序种子对全部场景、决策器、质量种子和配置使用同一格子排列。种子先在场景内平均，再按场景、事件平均；事件等权。
- 原规划器按相同公开参数和状态合并候选，只保留最小格子索引。新包装器把等价类的相同Q值还给全部合法格子，再比较同分顺序。三种规则使用相同候选集合，没有截断。规划Q的原有1e-12容差及次级数量贪心效用不变，仅改最终同分依据；贪心保留严格分值比较。

运行协议在读取观测缓存、生成轨迹前冻结于 `protocol.json`。原始模型与旧结果均按完成收据核对，未修改旧代码或旧输出。

## 主要设置结果

下表为不同目标建筑数/场景，先事件内平均、再事件等权；两列拟合范围都属于已查看的开发数据。

| 决策器 | 同分规则 | 全开发拟合 | 开发事件留出 |
|---|---|---:|---:|
| 数量贪心 | 行列 | 5.666667 | 4.752778 |
| 数量贪心 | 原始变化分数 | 5.663889 | 4.972222 |
| 数量贪心 | 固定随机，10顺序均值 | 6.048611 | 5.065000 |
| 两步前瞻 | 行列 | 5.672222 | 4.747222 |
| 两步前瞻 | 原始变化分数 | 5.641667 | 4.994444 |
| 两步前瞻 | 固定随机，10顺序均值 | 5.989167 | 5.042222 |
| 批量尾项 | 行列 | 5.833333 | 5.025000 |
| 批量尾项 | 原始变化分数 | 5.758333 | 5.202778 |
| 批量尾项 | 固定随机，10顺序均值 | 5.996111 | 5.211111 |
| 原始变化排序，只初查，上一轮固定参照 | 原规则 | 6.105556 | 6.105556 |

数量贪心随机同分相对行列增加0.381944（6.74%），开发事件留出增加0.312222（6.57%）；两个有检出目标的开发事件方向均为正。同分时使用原始变化分数，全开发拟合反而减少0.002778，不能说已证明“四档量化丢失的原始排序就是主要失败原因”。随机同分改善的是实现对照，不构成新方法或独立有效性证据。

同用随机同分时，批量尾项在全开发拟合比数量贪心少0.052500，Harvey和Santa Rosa均更低；开发事件留出多0.146111，但Harvey为正、Santa Rosa为负。三个匹配阈值下，这个正负方向均相同。批量尾项在开发事件留出仍比原始变化排序少0.894444（14.65%）。不得用“随机同分批量尾项”对比“行列同分贪心”来单独归因规划效果。

误报格/场景：全开发拟合数量贪心行列/随机为0.113889/0.118889，批量尾项为0.108333/0.120556；原始变化排序为0.186111。随机同分有小幅误报增加，因此不能只报发现数。开发事件留出数量贪心行列/随机为0.138889/0.148333，批量尾项为0.119444/0.136944。

原始变化分数同分并非在所有配置都无效；主要设置没有因此改动。全部质量、预算、成本、阈值、空间组和训练包络相交分层见 `summary.json`，逐场景配对比较见 `paired_effects.json`。

全开发贪心的跨格重复匹配从行列1.025000降至随机0.855278；变化分数同分也降至0.872222，但发现数未增加。这提示应继续分开检查重复、搜索顺序和复核预算，现有数据不足以把随机改善直接归因为空间覆盖机制。

## 验证与下一步

155项测试通过，包括等价类展开与小规模穷举Q值核对、原行列轨迹复现、固定随机顺序、严格贪心比较、无原图捷径/重复观察、未知真值字段无影响、场景与事件汇总等。

完整回放检查362,880条轨迹、6,502,956步动作、715,082次升级（70,003次来自模糊阳性）、1,088,640条阈值评分；30,240条旧规划轨迹包括分值逐动作一致。全部9,216个掩膜哈希核验；77,760次原图条件策略顺序不变量检查通过，5,184条主要配置轨迹重新执行完整决策。所有场景、事件、空间分组汇总复现。详细凭据见 `audit.json` 与 `completion_receipt.json`。

下一步计划见 `next_step_decision.json`，**尚未执行**：对只初查、仅阴性复核、全部复核及存在性效用补齐相同的三种同分规则，并保留原始变化初查/门控参照。这样才能判断复核机制的净收益，而不是比较不同同分规则造成的差异。旧输出继续保留，不提升规划深度、不把随机同分当成论文方法；完成基础对照后再决定是否继续这版复核路线。新方法和独立验证目前仍未成立。
