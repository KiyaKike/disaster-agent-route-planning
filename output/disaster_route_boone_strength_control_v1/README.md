# 修正强度匹配：6维差分是否提供目标选择性？

2026-11-03。复用同一组12栋初始分数、12个锚点和已付UAS视角标签。只做CPU数值计算，没有新增VLM调用、GPU租赁或路线运行。

## 本次问题与控制

上一轮固定旧核宽的6维组AP为0.474，超过原纯空间0.460，但其相似度均值达到0.922。本轮为每个锚点建立空间控制：保留原50m空间核，移除逐目标视觉门控，只使用一个标量系数，使其余11栋的**裁剪后平均绝对分数改变量**与对应视觉组完全相同。系数限制在[0,0.5]，80步二分解；不用未访问建筑的标签选择系数，不搜索最佳AP。

公式：视觉组为`clip(p_i + 0.5*w_ai*k_ai*r_a)`；空间控制为`clip(p_i + c_a*w_ai*r_a)`，求`mean(abs(control-p)) == mean(abs(visual-p))`，均不计锚点自身。控制仍保留视觉特征的汇总强度信息，因此准确名称是“移除目标选择性、匹配强度的空间控制”；它不等于完全不读取特征的固定空间基线。

这是查看上一轮结果后的开发诊断，不是预注册或区域留出验证。

## 结果

UAS作者视角标签作为参考；12个重叠锚点案例等权平均。

|视觉特征组|视觉组AP↑|匹配强度空间AP↑|视觉组减控制|视觉胜／平／负|
|---|---:|---:|---:|---:|
|原36维|0.435941|0.467141|−0.031200|3／2／7|
|仅6维，重估核宽|0.362848|0.456228|−0.093380|2／1／9|
|仅6维，固定旧核宽|0.474223|0.476439|−0.002216|1／9／2|

**固定旧核宽组的0.474没有超过匹配强度控制0.476；当前没有建立6维特征选择性的AP增量。** 与原纯空间0.460相比的提升，可以在移除逐目标门控后保留，说明反馈幅度足以解释目前的平均AP增量。不能由此推出所有视觉特征无效，也不能从12个重叠案例计算独立样本显著性。

其他指标也保留：固定旧核宽视觉组／匹配控制Brier为0.208733／0.208039，Log loss为0.606763／0.604843；前3名来源阳性数均值为1.000／0.917。前3名指标略有相反方向，不能把AP结论写成所有指标均无差异，更不能将其直接称为路线收益。NOAA来源参考的全部结果另列于汇总表。
