# 首个真实区域：保留拒绝案例

固定训练集顺序第一例 Sienna Village（Harvey），灾前卫星2017-02-16、灾后卫星08-30、无人机09-04。共同16栋建筑，固定128m区域内9栋中心；影像约29%无覆盖，完整可用1栋，无严重损伤目标。作者局部配准修正已应用，自动跨源特征匹配不足，独立绝对配准精度未确立。

该区域拒绝用于严重损伤搜查效益比较，保留影像、边界、筛选协议和私有参考，不运行感知模型追分。拍摄时间为作者元数据，32m窗口为图像访问单元，缺真实飞行轨迹／视场／能耗。部分字节构建的sparse.tif不是完整原图。

后续按原排序第二例推进，结果见[真实区域强对照报告](../disaster_route_crasar_region_rank2_v1/README.md)。本目录README.md是下载保留的作者数据说明，未替换为实验报告。
