# 最小研究筛选：复核有价值，是否就有新方法？

2026-11-03。**结论：停止把“保留多种解释、仅在路线分歧时考虑复核”作为独立新方法继续开发。** 在固定的有限策略空间中，该规则是标准贝叶斯信息价值决策的等价筛选写法，108个条件均与精确贝叶斯参考得到相同收益。没有发现独立方法贡献，不通过更换阈值或删除强参考追求优势。

## 问题与范围

协议先于本轮计算固定：[问题定义](problem_protocol.md)。Agent在家A收到一次阴性，面对两个初次观测不可区分的可能世界：目标概率低、检测可靠；或目标概率高、漏检严重。可继续去B搜索并返程，也可在A重采，或先付费获取一条用于区分世界的校准信号再选择后续路线。

校准动作是人为构造的可辨识性锚点，**尚无真实数据对应物**。重复观测采用“固定检测结果／条件独立重采”的混合，rho=1时持续漏检不会因重复观察自行恢复。无误报、目标静止、两个地点、最多一次校准均为筛选假设；这不是完整灾区、任意多步POMDP或真实无人机航线实验。

## 为什么这版筛选没有独立贡献

若各可能世界有共同最优的不校准路线a*，且复核不直接产生任务奖励、只压缩后续可行动作集合，那么复核后任何可选路线在每个世界中的收益都不超过a*。对校准信号和世界权重求平均，也不能超过直接执行a*。因此标准贝叶斯参考本来就无需购买这种信息。

当不存在共同最优路线时，本候选又直接调用相同的贝叶斯价值比较，所以两者收益一致。这里最多得到一个等价筛选／计算安排，尚无新的复杂度收益或决策保证；这段分析不主张新定理。
