# 只用建筑地理轮廓的空间筛查

固定 216 个候选，投影原始逐建筑 WGS84 轮廓及顶点数；不读取损伤列。读取范围核查未触及损伤载荷，新网络读取约 50.78 MB。来源和精确回执见 `spatial_protocol.json`、`report.json`。

- 62 个候选的建筑标注包络与公开训练池的包络存在正面积相交。
- 19 个没有可用建筑地理包络，保留为缺失，不计作“地理独立”。
- 在有包络的数据中，未发现跨开发/验证/确认分组的包络相交。
- 候选内部有两对同分组包络相交，可用于保守空间分组；214 个连通组中包含无包络的暂定单例，不能据此称为 214 个独立地理区域。
- 六个接口开发样本未触发训练包络相交。

建筑包络由已标注建筑的地理坐标构造，不覆盖完整图像。包络相交是风险提示，不等同于像素重复；包络不相交也不能排除完整图像重叠或地理邻接。这里没有取得官方完整影像足迹，也没有把源多边形推断成已验证的完整足迹。所有候选仍保持原清单，没有替换或按结果剔除。

本筛查不能证明感知器跨未见地理或灾害泛化，不能单独使整个 216 对数据通过准入。后续应补完整足迹或明确标记的推断空间范围，并保留当前结果以比较覆盖差异。
