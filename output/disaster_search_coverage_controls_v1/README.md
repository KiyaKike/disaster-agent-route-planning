# 均匀覆盖、随机搜索与复核拆分诊断

新增 25200 个回合，覆盖原来的 24 个校准场景与 24 个验证场景；复用 6048 个已经审计的旧策略回合。没有新模型推理、参数拟合或付费 GPU，test 仍未推理或评价。

后续早期探查识别性实验已完成，见 `../disaster_search_early_evidence_v1/README.md`。简单信号没有建立可靠切换依据；本轮原报告、参数和轨迹保持不变。

**本轮结论：粗图先验在校准场景中有实际排序价值，但这份小验证集上的优势很有限。当前局部反馈也不足以形成稳健的方法结论。后续应先检验早期观测能否识别先验不适用，并保留覆盖、复核作为强对照；不继续给现有传播规则叠参数追分。**

这是看过验证结果后的补充诊断。所有新控制定义在运行前固定，但不能据此重新称为盲验证。

## 最有用的对照

质量混合、每场景预算 32 时，跨 24 场景累计发现的不同目标建筑数如下。质量条件均值来自五种固定质量分配，随机方法再对十个固定顺序取均值；种子不是独立灾害事件。

| 方法 | 校准集发现数 | 验证集发现数 |
|---|---:|---:|
| 统一概率，原就近破同分，质量门控 | 175.6 | 8.2 |
| 空间均匀覆盖，质量门控 | 152.0 | 10.4 |
| 随机顺序，质量门控（十顺序均值） | 147.14 | 11.9 |
| 先验排序，只初查 | 201.6 | 12.4 |
| 先验排序加质量门控 | 222.8 | 12.8 |
| 再加局部正负反馈 | 227.0 | 13.0 |
| 随机初查精确期望 | 148.64 | 11.617 |

随机门控在该条件与预算范围没有触发升级，因此与随机只初查轨迹相同。随机精确期望描述的是理想均匀随机选格，不依赖本次十个顺序是否恰好有利；它不是新策略或真值输入。

校准集里先验只初查的 201.6 高于随机精确期望 148.64，说明不能因先验的概率误差较大就断言排序完全无用。到了验证集，先验只初查为 12.4、随机精确期望约 11.62，差距很小；在原图初查、预算 32 时，先验排序为 20，随机精确期望约 **20.227**，随机十顺序均值 20.7。这个验证子集没有显示强的可迁移排序优势。

验证质量混合、预算 32 的随机门控十顺序范围为 **10.2–14.2**，局部反馈的 13.0 落在该范围内。这是描述顺序敏感性，不是置信区间，也不能据此判定差异显著或不显著。相对随机均值，局部反馈仅多 1.1 栋，按场景平均后为 6 胜、15 平、3 负；目标验证仍只有 Michael 一个事件。

## 把复核收益分开看

每种覆盖排序都有“只初查”和“质量门控、允许升级”版本，两版共享初查顺序与观测质量分配。升级仍要求此前在同格取得模糊阴性，成本 2，替换旧证据；没有直接请求未访问格原图的新动作。

- 质量混合、预算 32：校准集先验排序从只初查的 201.6 提高到门控的 222.8，平均每场景升级 2.03 次；验证集只从 12.4 提高到 12.8，平均升级 1.58 次。
- 验证的全模糊初查条件下，所有只初查的覆盖方法都发现 0 栋；允许原图升级后，先验门控为 8 栋、随机门控为 6.5、局部门控反馈为 11。由于模糊缓存没有任何阳性，此处发现确实来自原图升级。
- 本代理把原图升级作为受控机会提供，不能解释成真正损失的影像信息可通过重新处理恢复。结果只说明这一预设复核机会在该实验中的作用，未证明复杂概率更新优于简单门控。

统一先验各格的初查效用相同。在质量混合条件下，每次升级效用又低于任何尚未访问格的初查效用，故预算不超过 32 时统一/空间/随机门控均不升级。相同动作库存不代表每组会使用相同数量的动作；本轮把实际升级次数显式列出。

## 首次发现与误报

验证质量混合、预算 32：

| 方法 | 平均误报格 | 有目标场景中，删失首次发现成本 | 发现目标的场景数均值 |
|---|---:|---:|---:|
| 统一先验，原就近规则 | 1.4 | 19.62 | 5.6 |
| 空间均匀覆盖 | 0.6 | 20.90 | 5.8 |
| 随机门控 | 0.54 | 21.176 | 5.82 |
| 先验只初查 | 0 | 20.42 | 6.0 |
| 先验加质量门控 | 0 | 20.42 | 6.0 |
| 再加局部反馈 | 0.8 | 18.86 | 5.8 |

删失成本在有标注目标的场景中计算：发现时用首次发现的实际累计观察成本，预算内未发现则记为预算+1，即 33。它是明确的截断诊断指标，失败不会被写成零耗时；无目标/不确定且无目标场景不加入该平均。另存仅对成功条件取平均的首次发现成本，不能单看该条件均值宣布策略更快。

局部反馈在这个成本指标上较早发现，但仍有较少的发现目标场景、更多误报，不能由单个指标宣布全面胜出。

## 控制定義与精确期望

统一先验固定为校准集原有的全局平滑目标比例，约 0.1590，没有使用验证目标比例。原就近规则保留先前选择器、距离破同分、相同行动成本；它与先验门控比较的是把先验空间分布打平后的行为。

空间均匀覆盖仅依赖公开网格坐标：从字典序第一格开始，每次在剩余格中选择距离已排格最远的一格；固定一次顺序后不看未来观察。它使早期观察分布在整张图上。当前不计移动成本，不能把均匀覆盖轨迹解释成节能航线。

随机覆盖用 `SHA256(search_seed|sample_id|cell_id|coverage_order)` 排序，十个 search_seed 固定为 20261030–20261039。初查与门控版本配对使用同一顺序；不根据目标或成绩挑 seed。

对仅初查的理想均匀随机抽样，总共 N=64 格，预算 k，某栋建筑能被固定结果检出的格数为 m，则至少发现一次的概率为：

`1 - C(N-m,k) / C(N,k)`。

对所有可检出建筑求和就得到去重发现数的精确期望，跨格的同一建筑不会重复加算。只有评价器使用这些目标匹配信息，规划器看不到。组合数实现与小规模穷举的结果一致。

## 现在的研究决定

1. **保留先验排序与简单门控作基线。** 校准数据的强优势没有完整迁移，不能简单归结为先验从来无用，也不能把当前局部修正当作已成立的方法贡献。
2. **下一个具体实验是“早期观测是否足以识别先验不适用”。** 先用固定数量的覆盖探查，检验仅从公开先验和已取得的观察，能否判断继续按先验搜索是否有价值。很多阴性可能只表示目标稀少，不必然证明排序错误；这一步要先检查信号是否可辨识，不直接训练一个切换器。
3. **识别成立后再研究预算分配。** 可检验的候选任务是：先验适用时保留排序，不确定或失效时如何分配覆盖与质量复核预算。当前只是由实验导出的候选问题，尚未核实文献新颖性，也没有提出或证明有效新方法。
4. **新增机制的确认需要新的独立事件。** 现有验证只有一个有目标事件，所有后续基于它的诊断都要标明已看过结果；测试小样本也仅 15 栋目标。扩展样本应先冻结独立协议，处理模型训练暴露，不能补挑阳性图改写本轮成绩。

当前计算足以继续做识别性检查，无需租卡或训练新感知模型。
