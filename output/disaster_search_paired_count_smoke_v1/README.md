# 成对观测与同格新增建筑数：组件检查

六个固定开发场景，382 对已知格，2 对不确定格排除。这里只完成拟合与接口检查，没有运行搜索策略，没有新方法成绩，也没有完成 72 场景开发拟合。

`component_parameters.json` 包含：

- 真值条件下模糊/原图的 2×2 联合分布，四个结果分别使用 0.5 伪计数。条件后验直接使用联合概率，避免将同源边际似然当作独立证据。
- 四个公开 RGB 变化分档中的原图/模糊局部匹配数量均值，以 8 个伪格作收缩。
- 按已观察模糊阳性/阴性区分的同格原图复核新增数量，拟合标签为原图匹配集合减已模糊匹配集合。

单元测试用有相关性的手工列联表验证联合更新，测试同格已发现建筑不重复奖励、拟合参数不暴露实例 ID、没有样本支持的观察条件返回不可用而非假零，以及模糊阳性仍可产生新增匹配。

模糊阳性条件本轮仅 1 格，估计缺乏支持。**跨格已经发现同一建筑的收益折减尚未实现。** 真实评价中原图有 8 次匹配、只对应 6 栋建筑，说明不能把每个格的预测数量直接当作全局新增不同建筑数。当前只能称为“局部数量效用组件”，不能称为完整、验证有效的搜索基线。

模型拟合使用评价器生成的训练标签，只输出汇总参数；行动评分接口只接收公开 RGB 分数、已付费的模糊结果、场景质量分配和成本。保留该信息边界后，下一阶段再设计跨格重复折减并扩展开发拟合。
