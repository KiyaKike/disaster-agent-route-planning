## 本次最后一次表征测试

选用用户建议中的归一化相关性分支，未新增深度模型下载或推理。每栋仅取原建筑掩膜内对应的灾前／灾后卫星像素，不使用灰色填充背景；分别计算R、G、B通道的Pearson相关系数，取`f=1-mean(corr_R,corr_G,corr_B)`作为1维变化特征。

对每通道单独中心化和归一化，故它对两个时相各自的正比例缩放、常数平移不变，比直接RGB展平能更明确去掉通道颜色偏置；它不能消除所有材质差异、局部阴影、遮挡或配准误差。所有通道无纹理时应报未定义，本批12栋均可计算。与旧协议相同：按未标注全队列标准化、标准差下限0.05，Gaussian特征核宽固定取正距离中位数，本次为1.061965；空间尺度50m、残差系数0.5。没有搜索核宽。

各锚点控制继续严格匹配裁剪后的平均绝对更新幅度，不用候选标签挑系数。归一化结构组相对该控制：AP增加0.108028，NDCG@3增加0.109702，Brier从0.201414降至0.196629；AP胜／平／负=8／0／4。累计Top-3命中却少1次，命中胜／平／负=3／5／4。

## 裁决与下一步

1. 原36维颜色与6维原始差分均未超过自己的幅度匹配控制，停止对其调核宽。
2. 新增Pearson组通过本区域AP比较，且NDCG@3改善；未通过Top-3命中与B11/B09修复要求。按本次筛选口径为“混合证据，保留一次路线检验”，不能写成“任何视觉相似性均无用”或“物理距离完全决定误差”。
3. 下一项冻结Pearson候选及原空间基线，接入已有Boone多步档案回放。固定共同p0、原几何、移动／观察／更新／返程预算，比较距离优先、充分求解静态、固定先验在线、纯空间反馈在线和Pearson反馈在线。主问题是预算60／100／140代理秒下的来源阳性核查数及首次到达时间，完整记录距离和耗时；不再看本区域结果改核宽。多步残差固定为新锚点标签减更新前该点分数，证据层只写已访问观测，已访问点不再候选，重复观测不累加收益。这里仍是标注辅助档案回放。

本轮未跑跨源分歧分支：当前没有冻结的NOAA模型初始先验，现有NOAA作者标签不能代替模型输出；主协议中目标NOAA影像为评估／QA用途。若以后假设全域NOAA出发前已可用，需要另列输入合同，并让所有方法获得相同资料，同时把NOAA参考评分作为同源诊断单列。当前归一化相关性已完成用户给出的表征备选，不混入未来NOAA证据。
