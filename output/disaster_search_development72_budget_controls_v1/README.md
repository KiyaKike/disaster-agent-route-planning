# 72 开发场景：预算对照与下一步决定

**本轮预算对照已完成。主要设置下，简单的“允许阳性复核”数量贪心降低了总发现数；暂不将它作为主方法，也没有证据支持数量效用优于简单存在性效用。** 后续应先检查剩余预算与跨事件拟合误差，补充预算感知的规划强对照，再判断是否存在值得提出新机制的空间。

本轮全部使用固定的 72 个开发场景与已有缓存。没有新增感知推理、下载、租 GPU 或新控制器训练；验证和最终确认未评分。所有事件都在固定感知器训练池中出现，完整影像空间独立仍未核实。

主要设置为质量混合、预算 32、原图复核成本 2、可见轮廓覆盖 10%。每个场景先平均随机顺序和质量种子，再平均事件内场景，最后对三个事件等权平均。下表单位为不同目标建筑/场景，**不是 72 场景总数**。Mexico 因固定模型未匹配其 3 个目标而为零，仍保留在分母中。

其他简单对照在主要设置下：随机初查 5.596、行优先覆盖 5.367、随机初查/复核 5.296、先验加模糊阴性复核门控 6.181。门控的已知阴性误报为 0.194 格/场景，数量复核两版本均为 0.114，不能只按发现数宣称全面更好。主要表的完整指标见 `report.json`，逐场景、事件及空间组见 `scene_means.json` 与 `summary.json`。

## 为什么“阳性复核还能找建筑”没有变成净收益

上一阶段拟合的 1.81 是在模糊阳性后，原图相对模糊新增的**同格匹配次数均值**。它没有扣除其他格已发现的建筑，也没有计入两单位复核预算挤掉的初查机会。

本轮实际去重计分中，允许阳性复核的策略在主要设置下平均进行 0.392 次阳性复核，直接新增约 0.750 栋不同建筑/场景；但它的总发现数仍比只允许阴性复核低 **0.400 栋/场景，约 6.6%**。前者是轨迹内直接归因，后者是两套完整动作轨迹的配对总差，不能相互替代。

| 事件 | 仅阴性复核 | 允许阳性复核 | 总发现差 |
|---|---:|---:|---:|
| Harvey | 10.642 | 9.625 | -1.017 |
| Santa Rosa | 7.558 | 7.375 | -0.183 |
| Mexico | 0.000 | 0.000 | 0.000 |

留一开发事件拟合时，同一比较的事件等权平均差为 -0.050 栋/场景。两个有匹配目标的事件方向也都为负。

一个事后挑选的说明例子：Harvey_00000125、质量种子 20261026 中，允许阳性复核直接通过这些复核找到 8 栋新建筑，但总计只有 36 栋；仅阴性复核的轨迹找到 45 栋。该例只解释机制，不替代全部场景统计。可检查两条完整动作轨迹于 `illustrative_cases.json`。

## 本轮实现的对照

12 个策略采用相同初查观测、可复核动作、质量分配和预算；消融明确关闭部分动作。原图观察后终止，模糊后最多一次原图复核，没有直接跳到未访问格的原图，没有重复消费同一条件。

数量模型复用固定开发参数：四档公开变化线索、8 伪格收缩、原图减已见模糊匹配的同格增量。模型没有解决精确全局不同建筑收益。阴性/阳性复核版本使用同一组数量参数，区别仅为动作资格。

存在性模型使用同样四档线索，对已知目标格拟合伯努利先验；先验向 Jeffreys 平滑的全局率收缩 8 个格。使用已拟合的成对模糊/原图联合似然，阴性复核用条件原图检出概率，不把相关边际似然独立相乘。它奖励第一次声明目标格，因此模糊阳性后的额外存在性效用为零。它是明确的目标函数消融，不是不同观测权限。

粗图面积控制仅从初始相同的 128×128 BOX 降采样灾前后 RGB 中计算两图均非零的比例，每格对应 16×16 粗像素。没有查看未来高分辨率局部输入，没有删除格或按标签过滤。面积覆盖相对行优先覆盖增加约 0.181 栋/场景；面积加先验相对原始先验只增约 0.025。这个简单控制未消除数量复核版本的主要失败；也不能据此把全零定义成已核实 NoData。

“只看另外两个开发事件”的数量/存在性参数完全不含被留出事件的拟合行，种子与主要设置相同。它暴露的是开发迁移问题，不是新验证集结果。所有参数文件均保存在 `models.json`，不包含真实建筑 ID。

## 核查与保存

共 **293,760 条轨迹、881,280 条固定阈值评分、5,360,432 个动作**，包括 220,296 次复核、6,533 次阳性复核。每场景 4,080 个固定配置，包含完整预算/成本/质量网格和一组主要设置的开发事件留出诊断。随机策略十个顺序种子，所有策略五个质量种子；重复原图场景种子不提供额外独立证据。

完整轨迹核查通过：动作输出字段白名单、先初查再复核、原图终止、实际付费结果、固定质量分配、预算约束及消融资格逐步核对。全部三个阈值的评分由保存轨迹重放，拟合行清单也核对了开发事件留出。133 项测试通过；所有上一阶段开发拟合输出及旧六样本实验保持一致。

输出分工如下：`protocol.json` 在运行前锁定规则、种子和输入/代码哈希；`trajectories.jsonl.gz` 仅保存动作及付费二值预测；`metrics.jsonl.gz`、`paired_effects.json` 与 `illustrative_cases.json` 属于评价器侧记录；真实建筑 ID 没有进入选点函数。压缩轨迹约 54 MiB，评分约 15 MiB；本轮规划约 30 秒，完整主运行约 51 秒，另计核查与绘图。

空间组和训练标注包络相交分层已另列。缺地理轮廓的场景仍标为未核实；组号不代表已经证明影像独立。Mexico 不作为成功迁移事件。没有应用未来的验证继续阈值来给这批开发数据宣告“通过”。

## 下一步应做什么

**优先补充预算感知的短视野规划对照，研究“复核的机会成本”，并同时检查数量模型跨事件失配。** 本轮说明了直接新增、成本比值贪心和最后的总发现数可能不同，仅提高复核概率或继续加折扣参数没有现成的收益依据。

下一轮先完成三个可检查产物：明确强对照的动作/成本/相关观测适配方案；在开发侧比较相同拟合参数下的贪心与规划；同时用全部开发拟合及留一开发事件参数报告结果。参数、规划深度/计算预算和随机种子须在新的执行协议中固定。若规划仍不胜过原始变化排序和简单门控，应停止增加控制复杂度，转而定位感知/数量校准或数据设置的问题。

这只是后续候选实验安排，尚未实现或运行，不能称为复现 ENS/MF-ENS，也不构成新颖性结论。强对照、完整准入和方法范围锁定后，再安排验证/最终确认；当前不打开它们的结果。
