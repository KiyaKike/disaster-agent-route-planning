# 冻结Pearson算子：Boone外三区域同预算检验

2026-11-03。完成3区域、3预算、6策略共54条闭合路线；原四区域中的Kennedy Green继续按灾前单通道排除，没有替换样本。**主预算下，Pearson没有超过强对照，保留为标准比较算子，不提升为研究主方法。**

## 同预算合同与强对照

- 不在Boone继续试特征。`1-mean(r_R,r_G,r_B)`、标准差下限0.05、特征距离中位数核宽规则、50m空间尺度、0.5增益、分数／距离选点全部固定。不同区域只按同一无标签规则计算自身核矩阵，不用来源标签挑参数。
- 主预算100，敏感性预算60／140代理秒；移动速度5m/s、每栋观察10s、每次更新／选路1s都是固定代理假设。每次选点先核验移动＋观察＋返程能否支付，不能用完预算再补返程。
- 在线策略每次决策尝试收费1s，包括最后一次发现无可访问候选的决策；精确静态一次规划收费1s。真实计算耗时另记，不冒充实测飞行时间。精确静态的几何DP离线预计算也另报，未当作实测航时。
- 起点为原128m区域南边中点，无免费已知锚点。每次抵达建筑且支付观察费用后，才读取该栋作者UAS视角标签。已访问点不再候选、收益不重复；新反馈残差减当前分数，不重复叠加初始残差。
- McGregor有2栋未分类建筑，仍可被选中并消耗预算，但标签不当负例、不给反馈更新，单列未知核查数。不能依据评估标签预先排除。
- 强对照包含距离优先、固定先验在线、原0.5空间更新、幅度匹配空间更新和精确静态。静态仅用共同p0最大化可行访问集合的分数总和，Held–Karp穷尽子集并验证Bellman递推；无标签参与规划。18／8／6栋分别枚举262144／256／64子集，共9份零最优性差距证书。
- 来源阳性与全部未来记录仅在独立评价中用于计分和事后上限；事后上限不参与任何选点。

## 输入与任务范围

共同p0使用与Boone相同的SmolVLM-256M冻结revision、无历史Prompt、双时相建筑掩膜裁剪、A/B及其前导空格token合并打分。新增32次先验前向均在本机MPS完成，测得调用合计约14.37秒；没有历史VLM推理、训练、新权重下载、付费API或GPU租赁。

本轮每次付费观察单位是**一栋建筑的来源标注访问**，与Boone逐栋实验一致。旧四区域实验是32m窗口加固定感知器的损伤检出回放，任务单位和反馈不同。所有基线均在新合同重跑，不能把本轮数值与旧3/9、2/9等直接解释成识别或方法提升。点位观察范围与10秒服务时长是假设，不是测得的无人机覆盖细节。

这三个区域在Boone之外，但属于同一Hurricane Ian事件的训练开发资料，且已被先前项目检查；本轮没有拟合或选择参数，不等于从未查看的独立测试集或跨事件泛化。独立配准证书仍未建立，Iona既有匹配残差问题保留；不据此为当前退化指定未经验证的原因。

## 裁决

Pearson算子与路线接口已冻结，形成可复用对照；本批未建立超越纯空间与充分求解静态的稳定路线收益。停止以这批数据为依据继续调Pearson参数或开发更多低阶表征。不宣称视觉信息普遍无用，也不把两步初筛替代区域外结果。

下一项研究决策应围绕“什么已付信息能带来强静态无法替代的路线增量”，先核验信息、动作与预算收益的对应关系；保留精确静态和同预算接口。没有新的证据条件，不恢复已停止的视觉核调参。感知阶段材料与Boone全部历史结果保持原字节，便于汇报。
