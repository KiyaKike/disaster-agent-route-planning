# 统一同分规则后的复核净收益

2026-10-25。**完整运行和审计已完成，执行此前冻结的停止条件：当前“同格数量效用＋允许阳性复核”方案停止作为主方法推进。** 这不意味着所有阳性复核都无用，而是当前固定模型、成本和主要设置没有一致净收益。原始变化排序和简单阴性复核保留为强参照；尚未选定新论文方法。

## 本轮设计与边界

只用72个固定开发场景、9,216个感知缓存及上一轮已拟合模型；不重新拟合、不新增推理、下载或租GPU，验证/确认没有评分。运行协议先于读取观测和生成轨迹冻结于 `protocol.json`，依据为上一轮 `next_step_decision.json`。

六种策略分为三组：原始变化排序的只初查/阴性复核；同一数量效用的只初查/阴性复核/全部复核；原有存在性效用参照。同一效用族只改变复核动作资格。阳性表示当前已付费的模糊观察结果，不读取未来原图或真实标签决定是否复核。存在性保持原来的阳性追加效用0，不另加新规则。

同分规则为行列、原始变化分数、固定随机格子顺序；严格分数比较，只对完全相同的分数使用同分顺序。沿用全部10个随机顺序种子和5个质量种子，轨迹内顺序固定；先平均每场景的重复，再在每事件内平均场景，最后事件等权。不同种子不当作独立灾害。

全开发拟合跑全部3种质量×3预算×3成本；开发事件留出使用已有另外两个开发事件的模型，只跑主要配置。主要设置仍为混合质量、预算32、复核成本2、匹配覆盖10%；全部固定轨迹按5%/10%/25%覆盖重算。阴性/零目标场景及Mexico全部保留。

上一轮数量贪心的120,960条轨迹逐配置核对后复用，去掉冗余的 `greedy_utility` 字段，仍全部重新评分。其 `planning_s=0` 表示本轮没有重算决策，不能用于声称该策略计算免费或与其他策略作新耗时排名。

## 主要设置：统一随机同分

下表使用全部10顺序均值；单位为不同目标建筑数/场景，误报为误报格/场景。

| 数量效用，只初查 | 6.050556 | 5.365833 | 0.125278 | 0.143611 |
| 数量效用，阴性复核 | 6.100833 | 4.924444 | 0.124444 | 0.151389 |
| 数量效用，全部复核 | 6.048611 | 5.065000 | 0.118889 | 0.148333 |
| 存在性效用 | 6.101944 | 5.216944 | 0.124444 | 0.135556 |

原始变化策略不使用拟合参数，因此在两个拟合范围中的结果相同是设计必然，**不是两次独立验证，也不是未见灾害泛化证据**。本轮随机同分也用于原始变化排序完全同分的格子，故其只初查/阴性复核从旧行列的6.105556/6.180556变为6.140278/6.215833；不能混用新旧同分规则比较复核收益。

阴性门控在这组开发结果中仍有最高发现数，但同时误报高于数量/存在性策略；没有给误报设新权重或综合得分，不能称为所有目标下的最优方案。

## 净收益与事件差异

| 相同效用族内的比较 | 全开发净增 | 事件留出净增 |
|---|---:|---:|
| 变化排序：阴性复核 − 只初查 | +0.075556 | +0.075556 |
| 数量效用：阴性复核 − 只初查 | +0.050278 | −0.441389 |
| 数量效用：全部复核 − 阴性复核 | −0.052222 | +0.140556 |
| 数量效用：全部复核 − 只初查 | −0.001944 | −0.300833 |

原始变化阴性门控只有约1.23%发现增量，误报增加0.008333格/场景。收益来自Santa Rosa的+0.293333，Harvey反而−0.066667；Mexico为0。因此不能从最高开发平均数直接认定阴性复核值得作为新方法。

数量阴性复核在全开发拟合略增0.050278，但事件留出损失0.441389（−8.23%）。其中Harvey−1.633333，Santa Rosa+0.309167，表现出明显事件差异。复核本身能找到目标不代表它抵消了少搜索其他区域的机会成本。

阳性复核在全开发拟合的主要设置每场景直接新增0.796389栋，却相对阴性复核净损失0.052222；事件留出直接新增0.656111栋，相对阴性复核补回0.140556，但仍比只初查少0.300833。直接新增与同预算净收益必须分开。

在主要10%阈值下，三种同分规则×两个拟合范围共六个配置中，数量全部复核均低于数量只初查；当前方案满足此前停止条件。不得从“全部复核优于一个更差的阴性复核方案”推出它优于只初查。

## 已完成的差距分解

`score_gap_decomposition.json` 仅从完成的汇总结果作事后描述，不重新评分或拟合。它是策略分数之间的代数恒等式，**不是相互独立的因果误差分解**。2,016个事件/事件宏平均差距等式全部闭合。

以随机同分、事件留出、数量全部复核相对变化阴性门控为例：

- 数量只初查相对原始变化只初查：−0.774444；在不复核时差距已经存在。
- 加数量阴性复核：−0.441389。
- 再允许数量阳性复核：+0.140556。
- 原始变化门控比其只初查多0.075556，作为基线的额外优势需扣除。

合计−1.150833，正好等于5.065000−6.215833。这说明下一阶段应分开检查效用排序跨事件失配和复核估值，继续加前瞻深度无法据此解决问题。
