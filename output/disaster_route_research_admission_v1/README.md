# 研究立项审查：付费复核是否真的构成新问题

2026-11-03。**结论：上一轮“联合判断先验与观测可靠性，再决定复核”的表述仍过宽，不能当作已发现创新，也不直接进入算法开发。** 本轮完成近邻文献与公开代码审查、24场景元数据核验，以及一个使最优路线翻转的精确可辨识性反例。它们是研究筛选证据，尚非新算法、新定理或灾害实证收益。

## 2. 一个确实影响路线的障碍：观测相同，正确行动却相反

在无误报、目标概率p与检测灵敏度s均未知、每个位置只观察一次、无额外质量线索的简化模型中：

**检出概率 = p×s。**

|可能世界|目标概率p|灵敏度s|初次检出率|收到阴性后该位置仍有目标的概率|
|---|---:|---:|---:|---:|
|先验高估、检测可靠|0.2|1|0.2|0|
|先验较高、漏检严重|0.8|0.25|0.2|0.75|

任意数量的独立位置初次观测，在这两个世界中都有相同分布。不能仅凭这些观测同时识别p与s。已用分数精确核验样本量1至12的90项计数概率等式；对任意样本量的结论来自上述代数等式，不来自有限样本模拟。

路线反例：Agent在A收到一次阴性，家就在A，剩余预算2；每次观察收费1，A到B距离0.5且移动单位费用1。可选择“到B观察一次并返程”，或“在A最多再独立采集两次，检出后停止”，两者费用上限均为2，同一目标不重复领奖。

|行动|先验高估世界的期望发现量|漏检严重世界的期望发现量|
|---|---:|---:|
|访问B并返回|0.2|0.2|
|A处最多两次独立复核|0|0.328125|

因此，同样的初次观测历史对应相反的最优选择。后续真实独立采集、可靠校准锚点或有效的观测质量信息可能打破歧义；同一影像重复裁剪、同一检测器重复读图不能替代它们。该反例没有证明现实数据普遍不可辨识，也不宣称这是新定理。条件独立、无误报、同一状态等假设均明确写在identifiability_witness.json。

## 3. 我们现有数据是否能验证这个机制

仅核查固定版本CRASAR目录与文件清单，未按损伤结果选例、未读取新标签或下载新影像：

- 原24个有灾前／灾后卫星及UAS的训练场景，来自Harvey 1个、Ian 23个，不能视为24个独立事件。
- 21个有与当前灾后卫星同日的额外来源记录，18个含同日有人机记录，可作为后续复核数据的候选入口。
- **与UAS同日的额外来源记录为0。** 对这24个精确场景名，未建立同状态独立UAS复访或共同现场真值。
- 同日文件也不等于同时拍摄、同一目标可见、误差独立或有真实损伤参考。未证明不存在其他数据源或跨场景重叠复访。

所以现有资料可支持受限的档案证据揭示研究，但不足以直接实证“无人机漏检后复飞即可可靠归因”。作者视角标签之间的差异也不能直接标为“先验错／检测器错”；真实变化、遮挡、配准和标注差异均可能造成冲突。详细候选清单见verification_catalogue.json。

## 4. 只保留一个更窄的候选问题

**在原因尚不可唯一归因时，哪些额外观测能够改变剩余预算下的路线选择，因而值得花费复核预算？**

这是待审查的新假设，不是已确认的新颖贡献。重点从“解释所有冲突”收缩到“消除会改变行动的歧义”：若与历史相容的模型给出相同最优后续路线，则不必为区分原因额外花预算；若它们推荐不同路线，才比较具体复核动作能否消除分歧，以及它挤占了多少搜索、移动和返程预算。通用价值信息、贝叶斯自适应或最小最大遗憾本身均不能被重新命名为创新。

双层地图接口保持原含义：先验／线索层保存搜索判断；证据层只记已付观测的原始来源、时间、覆盖与质量依据。候选行动的实际预测、可见性、冲突值和标签，在付费前不能读入策略。

## 5. 决定是否继续的最小实验合同

1. **新颖性关**：与固定误差概率搜索、Search-TTA、可见性门控、公开主动视角选择及任务导向信息规划逐项对照。必须指出新模型假设／算法保证／可验证机制，不能只以灾害场景、双层地图或平台变化作为算法贡献。
2. **数据关**：至少一份可核验的独立复核来源或校准锚点，并说明同一建筑、时间差、观测质量与参考标签的来源；不能由额外裁剪或生成图像补造。先从18个卫星／有人机同日候选的元数据检查入手，是否能用于UAS问题仍须另证。
3. **机制关**：保留“先验错”“观测失效”“二者混合”“额外复核无信息”条件；先用已知模型求小规模最优值，确认复核确有行动收益。受控模型只能验证机制，不能代替真实灾害结果。
4. **方法关**：相同可用信息和闭合预算下，比较不复核、始终复核、冲突／不确定性优先、充分求解静态及成熟自适应参考。归因更准但最终有效核查不增，或成本抵消收益，都不支持方法贡献。

**当前决定：不批准把泛化的“可靠性＋付费复核”作为新方法直接开发；更窄命题保留为未确认候选。** 本轮停止扩旧启发式、调阈值和增加感知训练。下一项工作是核实一个真正可用的独立复核数据入口并继续排查近邻方法；若两关都无法满足，应放弃该候选，不再用系统工程补强来延后决定。

已保留此前感知检查和全部封存实验。无训练、无新增模型调用、无GPU租赁。
