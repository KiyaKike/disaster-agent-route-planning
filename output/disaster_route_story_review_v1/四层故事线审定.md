# 四层故事线审定：现象、计算机制与未确认原因

2026-11-05。核验对象是现有实验故事线，不是论文正文。本轮只复查记录，不改模型、路线、核参数或数据集合。

**总判断：四层可以作为逐步收紧评价的诊断链成立，不能写成四次独立验证同一假设的证伪定理。** 这是一条事后整理的开发研究链；各层任务和比较合同不同。最有证据的主结论是：局部评分增益不足以保证同预算闭合路线收益，当前固定候选未在这些区域稳定超过强参考。尚不能确定失败主要由哪类物理噪声或区域差异造成。

## 第一层：受控信息成本边界

|判定|核验内容|
|---|---|
|已证实的现象|有限策略族、108条件中，强制校准60次比不校准静态更差；可选校准11次改善；候选与同策略空间精确贝叶斯参考108次收益相同。|
|已明确的计算机制|校准动作没有直接检出奖励，支付采集及额外规划费用后，可行尾部路线集合缩小；这是代码与问题合同的确定属性。|
|仍未确认|真实无人机任务中这种效应占多大比例；有噪实测校准源的价值；感知、移动、重规划各费用的单独贡献。没有对应真实传感动作Q。|
|需要改写|“理论证明在线复核通常失败”改为“在指定有限模型与参数网格中，强制校准常低于不校准参考”。11/108是可选校准胜过静态的网格计数，不是候选胜率或真实灾害概率。|

不能把共同尾部最优条件下的等价性分析称为新定理，也不能把校准预算竞争称为本项目首创机制。预算费用由协议给定，不等于已测量真实飞行能耗。

证据：[108条件原始结果](../disaster_route_verification_screen_v1/results.json)、[冻结问题合同](../disaster_route_verification_screen_v1/problem_protocol.md)。

## 第二层：固定小VLM与低阶表征

|判定|核验内容|
|---|---|
|已证实的现象|Boone12栋、276次正式前向；完整历史AP0.341964，不更新0.377447。12/12锚点中，全部未访问目标的分数沿锚点标签方向移动：9个阴性锚点均降、3个阳性锚点均升。|
|可确认的计算事实|36维中30维为灾后颜色统计，6维为原始差分；B11—B09平方特征距离约97.6%来自灾后颜色统计。阴性残差乘小相似度会减少扣分，使某些目标得到更大保护。|
|仍未确认|同向偏移是否是模型只利用标签的捷径，还是当前Prompt／小模型能力／视觉输入交互的结果；静态屋面颜色是否是真正误报诱因；相关性异常是否主要由配准造成。|
|需要改写|“端到端VLM被证明退化为标签捷径”改为“该固定小模型配置表现出与锚点标签一致的全局同向偏移”。本轮没有端到端训练，完整历史与仅标签消融也不相同，不能写成模型完全忽略图像。|

低阶表征的**AP**均低于各自幅度匹配空间控制：

|表征|视觉组AP|匹配空间AP|
|---|---:|---:|
|36维|0.435941|0.467141|
|6维，重估核宽|0.362848|0.456228|
|6维，固定旧核宽|0.474223|0.476439|

这支持停止本批AP导向调参，但不支持“所有指标均无收益”：6维固定旧宽Top-3累计12次对11次，差异仅来自B01。幅度匹配控制匹配的是每锚点、未访问集合的**裁剪后平均绝对改变量**，仍保留特征的汇总强度信息，不能叫完全不读取视觉的空间基线。

B10为UAS视角无损，平均Pearson约−0.123905，确属负相关；但没有独立纠偏后对照，不能推出“负相关测到的就是错位”。阴影、遮挡、分辨率、视角和时相变化均未被分别操纵。

证据：[预测与消融表](../disaster_route_four_stage_evidence_v1/boone_prediction_metrics.csv)、[12锚点方向](../disaster_route_four_stage_evidence_v1/vlm_direction_diagnostic.csv)、[特征距离组成](../disaster_route_boone_feature_error_audit_v1/feature_distance_components.json)、[逐通道相关性](../disaster_route_boone_structure_check_v1/structure_features.json)。

## 第三层：真实局部增益与单点敏感性

|判定|核验内容|
|---|---|
|已证实的现象|Pearson AP0.553475对幅度控制0.445448，Top-1累计9对1；7次首选同一B03。仅从候选排序剔除B03后，Top-1为3对1，净优势8变2，仍有残余。|
|已证实的决策结果|带真实第二次来源标签反馈、分数／距离选点，两步累计8对5，3胜9平0负；返程总距离1198.87m对1145.48m。纯分数规则下Pearson9反而低于不更新11。|
|仍未确认|是否是一般过拟合、某种空间中心性、特定屋面或真实损伤特征导致；完整预算下能否保留收益；跨事件是否有效。|
|需要改写|“局部过拟合幻觉”改为“开发区域的局部增益具有主导目标敏感性，未建立泛化”。不是所有优势都消失，也没有用独立留出证明经典统计意义上的过拟合。|

剔除B03只是对冻结排序删除候选，不加入B03观测、不重新拟合核矩阵，因此不是第二步闭环；正式两步实验另有反馈合同。12个锚点重复评价同一批建筑，9次Top-1不是9栋独立新发现。两步初筛限定等新访问数，不是同航程或同时间预算。

证据：[逐锚点Top-k及删除B03结果](../disaster_route_four_stage_evidence_v1/boone_topk_node_sensitivity.csv)、[两步结果](../disaster_route_four_stage_evidence_v1/boone_two_step.csv)。

## 第四层：固定候选未通过区域外强对照

|判定|核验内容|
|---|---|
|已证实的现象|原固定四场景保留单通道排除，其余3区域54条路线。100代理秒合计精确静态5、纯空间4、距离／幅度空间／Pearson各3；Pearson对幅度控制1胜1平1负。所有路线含观察、决策与返程，预算违规0。|
|跨预算事实|60／100／140秒静态合计3／5／8，Pearson2／3／7。Iona100秒静态0、距离／空间1，静态并非逐地区支配。|
|已定位的局部计算机制|Iona同一已付历史下，I08阴性反馈使I07优先级由0.009559降到0.007556，I01仅由0.008401降到0.008211，导致选I01。此后再核查I07并返程需103.68s，超100s。|
|仍未确认|区域异构、配准噪声、目标稀疏性、在线贪心短视各自造成多少损失；是否改变规划器或服务时间就能改善；是否能推广到其他事件或真实飞行。|
|需要改写|“在线核无法跨越区域异构性、静态最稳健”改为“在三个同事件开发区域的固定逐栋档案核查协议下，当前候选未稳定超过强对照，静态三预算合计更好”。|

原始比较同时改变多个因素：静态用精确全局求解，在线用分数／距离贪心；静态付一次1s规划费，在线每次尝试付1s；各策略访问历史和候选状态也可能不同。这些均按原合同计入同一预算硬上限，但比较没有单独识别“在线机制”或“优化器”的因果影响。不能把所有差距归给视觉特征或配准。

Iona的具体分叉有同状态数值依据，强于物理归因：无须假定影像为何错，即可复算优先级反转和返程排除。Pearson最终航程更短、用时95.24s，不能写成“飞更远耗尽预算”。同时这只是一个局部分叉回看，没有运行强制I07后的完整替代策略。

证据：[54路线汇总](../disaster_route_crasar_pearson_isobudget_v1/summary.csv)、[固定预算及收费合同](../disaster_route_crasar_pearson_isobudget_v1/protocol.json)、[Iona分叉](../disaster_route_iona_ranking_diagnostic_v1/iona_fork.json)。

## 四层之间允许建立的联系

可以讲：受控例子提醒信息成本不能省略；小模型与表征对照排查了局部评分的假增益；单点敏感性和两步试验收紧初筛；区域外同预算比较检验当前候选的任务收益。四层共同形成一条**评价逐步接近最终搜查目标的诊断链**。

不能讲：四层证明了同一普遍失败定律。第一层是有人工校准信号Q的受限模拟；第二、三层使用Boone作者视角记录辅助反馈；第四层是逐栋付费档案核查。它们不是相同模型的四个独立测试集，也不是事先统一设计的确认性研究。

“排序—路线收益不单调”有配对反例支持：Iona同首访后AP0.143→0.200但路线命中1→0；DIRT AP0.724→0.416但命中2→3。它说明该排序截面不足以替代闭合路线评价，不证明AP普遍无用、统计独立或同预算收益由某一个因素决定。

## 后续统一使用的四层名称

1. 受限模型中的校准收益与费用边界。
2. 固定小VLM的同向偏移与低阶表征对照。
3. 开发区域的局部增益及主导目标敏感性。
4. 区域外同预算比较与日志分叉诊断。

当前可主张的是评价过程和受限范围内的实证发现，尚无新算法、独立现场校准或普遍因果结论。后续材料使用上述名称，不把“捷径陷阱”“过拟合幻觉”“静态最稳健”等判断写成已验证成因。写作仍后置；本轮不要求为完善故事线而启动新训练或调参。

## 核验与复现

[数值审计](numeric_audit.json)从原始分数、逐世界收益和路径记录核验8组关键前提，逐输入SHA256在审计内。核验程序不使用原始影像、不运行策略、不调用VLM：

```bash
python work/disaster_route/verify_four_stage_story.py --output output/reviewed_story_numbers
```

输出目录须不存在。脚本只确认数字、代码状态关系和反例；物理原因与外推判断不由数值断言自动认证。旧实验及上一版证据包均保持原字节。
