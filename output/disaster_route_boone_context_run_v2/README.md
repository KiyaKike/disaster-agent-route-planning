# Boone首轮上下文更新：已完成真实切片实验

2026-11-03。12栋固定建筑，12个锚点分别预测其余11栋；本机完成小VLM实际推理及统计对照。**当前小VLM完整历史没有带来收益；下一步检查更强VLM能否摆脱整体调分。**

## 结果

所有方法共用同一VLM生成的初始分数。以下为按锚点等权平均、以作者UAS视角标签作参考的开发结果；AP越高越好，Brier越低越好。

|方法|AP|Brier|前3名中的来源阳性数|
|---|---:|---:|---:|
|不更新|0.377|0.203|0.917|
|空间更新|0.460|0.209|0.917|
|视觉特征＋空间更新|0.436|0.206|0.917|
|VLM完整历史|0.342|0.223|0.667|
|VLM仅历史标签|0.306|0.209|0.167|

空间更新提高了AP，但前3名来源阳性数量与不更新相同；它不是已建立的路线收益。不更新的Brier最低。VLM完整历史在两项主要评分上均未优于不更新，也未优于两个统计参考；其AP略高于仅标签历史，但不足以支持当前配置进入路线闭环。

## 看到了什么行为

12/12个完整历史案例中，其余11栋的分数全部同向变化：历史UAS视角阴性时全部降低，阳性时全部提高。阴性锚点的平均变动约−0.045至−0.080，阳性约+0.166至+0.205；单案例变动标准差约0.009至0.017。

因此，这版模型表现更接近跟随历史标签整体调整判断，尚未显示预期的视觉选择性纠偏。这是对保留分数的行为诊断，不能当成模型内部推理的因果解释。

## 执行与证据

- 模型：[SmolVLM-256M-Instruct](https://huggingface.co/HuggingFaceTB/SmolVLM-256M-Instruct)，revision `7e3e67edbbed1bf9888184d9df282b700a323964`；MPS、float32、固定权重。
- 60张建筑掩膜切片已制作并目视检查；候选仅暴露允许的卫星图，锚点才提供UAS；NOAA图仅作检查。
- 正式比较276次前向：12次初始、132次完整历史、132次仅标签历史。实际前向累计约329.6秒，无API计费或GPU租赁。
- 6项测试通过；276次输入路径核对、60张切片哈希、40个独立汇总指标检查通过。标签token同时纳入裸字母与前导空格版本；最小答案集合概率质量0.951。
- 首次评分格式调试产生114次前向，因遗漏带空格答案token而不用于效果表；本机原记录在`../disaster_route_boone_context_run_v1/`，原因保留在[调试说明](scoring_format_note.json)。正式实验另用本目录，不覆盖调试输出。

## 下一步

固定当前切片与统计参数，选ID顺序前三个锚点，使用更强VLM重复“无历史／完整历史／仅标签历史”比较。先检查它是否仍全部同向调分；只有实际出现值得继续验证的增量，再扩其余锚点及接路线。不同模型各自生成共同p0，统计参考随其p0重算，不能让强VLM直接与旧模型弱先验比较。

本轮不调旧感知器、不追本区域阈值。新的明确问题是：**整体调分来自这个小模型的能力限制，还是当前上下文方式本身没有利用到可迁移的视觉信息？**
