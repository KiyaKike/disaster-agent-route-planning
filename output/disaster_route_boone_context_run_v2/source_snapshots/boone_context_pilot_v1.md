# Boone最小上下文试验：先检验反馈是否有增量

2026-11-03。开发性筛选协议；本区域及标签已在旧实验中查看，不能称独立测试集或未经查看的预注册实证。新增方案先于任何本轮VLM预测固定，不改变旧封存结果。

## 这一步回答什么

问题：给定一个已揭示建筑A的跨源资料，能否提高对其余建筑来源视角标签的预测？先把预测更新与路线规划分开。实验单位是同一Boone区域的12栋建筑，不是132个独立样本。

这是**标注辅助的档案证据访问实验**：历史可包含作者对A的UAS视角标注，作为有误差可能性的来源记录，而不是现场真值。实际部署中如何取得同等历史标注、需要多少费用，尚未建立。以后自动感知版本必须另做；不能把本轮标签直接说成无人机传感器自动返回的真实答案。

## 五个前提修正

1. UAS／NOAA标签不一致，说明来源记录有分歧；不能仅凭分歧认定UAS信噪比更高，或指定哪一方正确。
2. `verification_screen_core.py`的旧小模型无误报，含两种不同灵敏度世界和相关重复误差；它不是所有建筑共用一个已估计参数的完整现实传感模型。本轮不混用旧模型公式与真实图像分数。
3. 统计方法可以利用视觉特征、条件可靠性和非均匀核；各向异性更新不是VLM独有能力。只给统计方法距离、却给VLM图像，不能隔离VLM机制。
4. 从一张图像给出“可靠性低”的判断，不等于估出了检出率。`s=P(检出|真实受损,条件)`需要受损参考支持，当前不能由一句视觉解释识别。
5. VLM未赢，只能说明在该协议和样本下未显示增量；不能推出误差空间均匀，也不自动否定其他VLM或所有视觉条件更新。

## 样本与现有字段

- 固定旧128m区域及旧几何可用集合，保留全部12栋；不按标签冲突或方法表现挑锚点。
- 每栋轮流作A，其余11栋作候选，共12个重叠案例、132次目标评分。全部案例是相关的开发诊断；不得按132独立样本作显著性检验。
- 视角标签：灾后卫星4栋minor，UAS3栋minor，NOAA2栋minor；均无严重目标。任意损伤二值映射固定为minor／major／destroyed=1，no damage=0，其他为未知。
- 旧`prior_damage_score`是损伤像素比例，非逐栋受损概率；本轮保存为历史描述字段，不能当成贝叶斯先验或以其与VLM概率的Brier差直接证明校准优势。
- 时间：卫星与NOAA为2022-09-30目录日期，UAS为10-01；共同状态、精确时刻及独立配准精度均未建立。

## 逐案例信息边界

所有算法有相同的**可获取原始信息**；标量消融主动忽略图像，不能称与VLM同表征的强对照。

|资料|算法可否获得|
|---|---|
|所有12栋的建筑ID、几何、灾前／灾后卫星建筑切片|可以，按档案任务设定为出发前可得|
|本案例A的UAS建筑切片、作者UAS视角标注及日期|揭示A后可以；明确这是标注辅助反馈|
|A的NOAA图与标签|主试验不提供；可作为单独扩展，不能偷偷补入主历史|
|其余11栋UAS／NOAA图、来源标签、卫星人工标签|不可以；只由评估器使用|
|实际冲突原因、正确可靠性或真实损伤状态|未提供，不编造|

**裁剪也是信息边界。** 不能把整个UAS区域图给模型，然后声称只观察A。后续切片器只显示A建筑掩膜内像素，其余置中性背景，并保留掩膜、裁剪框和源哈希。卫星候选也按建筑掩膜处理；输入中不叠加损伤标签。该裁剪牺牲部分周边遮挡语境，是本轮边界；若增加上下文，必须先计算它是否揭示邻居，并将暴露集合计入已观测，另立协议。

独立配准不足时，掩膜与实际屋顶可能错位。切片可作输入检查，但不能凭它宣称已经对准同一物体；发现明显错位时记录并报告，不能看方法得分后选版本或删例。

## 对照与共同起点

固定一个VLM和完全相同的候选卫星图，先运行无历史版本，得到逐栋分数`p0`。它只是待评价分数，不是已校准概率。保存后冻结，所有反馈更新器使用相同`p0`。

|名称|输入和目的|
|---|---|
|S0：不更新|使用冻结p0，确认反馈是否必要|
|S1：空间残差更新|p0、A来源标注及距离；便宜的标量消融，不叫最强贝叶斯方法|
|S2：视觉条件统计更新|S1输入＋与VLM同样可获取的卫星／锚点图；固定特征、相似度或冻结编码器，检查非均匀迁移是否必须靠VLM|
|V0：VLM无历史重复对照|同版本、同候选图，测调用／格式变化带来的波动；不把它和S0重复算独立方法|
|V1：VLM完整历史|加入A的图像与有来源标注，保持候选图和输出定义一致|

S1可先固定为`clip(p0_i + 0.5 * exp(-d(A,i)^2/(2*50^2)) * (r_A-p0_A), 0, 1)`；这是分数传播启发式，不是由噪声似然推导的贝叶斯后验。50m与0.5仅为开发协议初值，不能在本区域标签上追分后称确认性结果。

S2至少加入预先固定的卫星颜色／纹理及灾前灾后变化特征相似度，使同距但外观不同的建筑能够不同更新。图像内容须与VLM合法输入一致；不能读取目标未来UAS特征。特征定义、归一化、相似度尺度及可靠性处理在看本轮预测前固定。不用12栋的目标标签训练可靠性分类器。低阶特征结果仅是最低对照；若主张VLM优于视觉方法，还需加入合理的冻结视觉编码器参考。

S2及相关参数尚未实现／冻结，是**阻止直接宣称公平胜出的待办**。没有可用强对照时，最多报告VLM与空间消融的探索差异。

建议消融：相同输出字段的“只有A标签、没有A图像”和“有A图像但没有A标签”；图像、文字分别是否提供增量要分清。错配历史仅作诊断，不把错误示例当正式历史。

## 提示与输出

Prompt只陈述来源和时间，不提前写云影、深色屋顶或“真值”。要求对候选输出`building_id, damage_score, used_evidence_ids, insufficient_evidence`；允许保持p0，解释只作审查记录，不能当冲突因果真相。

解析失败、缺ID、越界或使用未揭示证据时，按固定规则退回该目标p0，并记录失败；所有失败与费用保留。一个请求只允许本案例A的历史，跨案例不共享聊天记忆或评估标签。

## 评价与判定

主要终点是**与未揭示UAS作者视角标签的一致性**；NOAA作者视角标签作另报的敏感性终点。来源分别评分，不投票合成“最严格真值”、不挑对VLM有利的来源。NOAA2个阳性与UAS3个阳性不能被包装成充分统计功效。

报告每锚点和每目标的Brier、预定epsilon=1e-6的Log loss、AP、前3名来源阳性数；AP按并列分数一组处理。每锚点等权平均，并列出12个原始案例及所有独特目标；不通过重叠行数夸大样本量。Brier描述对该来源标签的评分质量，不证明真实物理概率校准。无阳性时AP记未定义，不补0制造优势。

本轮无路线和物理费用收益结论；记录请求数、耗时、输入图数／分辨率、模型版本、token与实际费用。模型尚未选定、合法切片未审查、预算未设定前不执行API；无需先租GPU。第一轮可仅用固定3个锚点做格式检查，按ID顺序选择并明确不是效果样本；完整12锚点留作既定开发对照，不按效果换例。

判定：VLM未优于S0／S1／S2，则该配置没有支持进一步扩展的证据，先分析失败而非改称误差均匀；仅优于S1但不优于S2，说明视觉信息可能有用，未证明VLM机制必要；跨来源方向相反，报告对来源定义敏感。即便一致优于强参考，也只足以进入其他区域的留出验证，不能直接称显著方法创新或真实飞行收益。

## 已完成和紧接着做什么

本轮只核对样本、已有分数语义、标签来源和信息合同，并生成案例索引；没有VLM调用、没有模型得分或胜负结果。
