## 数据边界

- 原始 PNG 与建筑 JSON 来自固定 commit 的社区镜像，来源、时间、SHA256、授权记录见下载目录 `SOURCES.md` 和 `manifest.json`。尚未与官方分发文件逐一校验，尚未独立核对原发布条款。

- `public_cues.json` 只由降采样图像生成，变化分数不是概率，`prior_probability` 保持 null；不读取标签，不自动塞入合成搜索器。

- 128×128 降采样只是粗分辨率代理，没有真实 PS 成像模型。单张卫星图的重复分析不等于多次独立无人机观测。

4. **真实影像代理搜索**：全局/局部反馈、均匀/随机覆盖、初查/复核拆分以及早期信号检查均已完成。当前几个简单机制没有充分证据支撑论文贡献；先解决新事件评价机会、权重暴露和评价目标，再决定新机制。已看过的验证数据只作明确标记的探索诊断，正式测试继续保留。
5. **加入移动和返程成本**：E0 仅计算观察成本；不能把它的预算解释成飞行分钟或实际航程。

## 结果解释

合成检查中质量条件模型直接知道模拟似然，属于理想校准条件，不证明真实可靠性已解决。`adaptive_prior` 只是带收缩的探索性启发式，并非已经成立的新方法。

小预算下，更新可能改变数值却不改变行动；正式报告应同时检查动作序列、补查和未访问区域排序是否变化。不能把数值变化等同于决策收益。保留失败与无增益结果，不通过针对测试场景调参制造优势。

继续标准：相较质量条件贝叶斯基线，在独立测试事件、同等成本下稳定改善目标发现且控制误报；若只在理想模拟噪声中有效，或简单质量门控已达到相同表现，应修改机制。
